# Publication List Compilation

This directory contains the LaTeX source files for generating the complete publication list PDF.

## Files

Only `main.tex` and this README are tracked in git. Everything else in this directory
is a build artifact and is gitignored.

- `main.tex` - Main LaTeX document (**the source**)
- `My-Publications.bib` - Copy of the master bib at the repo root, made by `make update-publist`.
  **Never edit it here** — it is overwritten on every build. The master bib is maintained by
  `make sync-pubs` from Zotero.
- `main.pdf` - Generated PDF (after compilation)
- `main.bbl` - Bibliography file (generated by Biber)
- `main.aux`, `main.log`, etc. - LaTeX auxiliary files

## Compilation Process

The publication list is compiled using the following steps:

1. **XeLaTeX** - First pass to generate `.aux` files
2. **Biber** - Process bibliography references
3. **XeLaTeX** - Second pass to resolve references
4. **XeLaTeX** - Third pass to ensure all cross-references are correct

## Usage

### Manual Compilation

```bash
cd publist
xelatex -interaction=nonstopmode main.tex
biber main
xelatex -interaction=nonstopmode main.tex
xelatex -interaction=nonstopmode main.tex
```

### Using Makefile

```bash
make update-publist
```

This will:
1. Compile the LaTeX document
2. Process bibliography with Biber
3. Complete the compilation process
4. Copy the final PDF to `static/uploads/pubs.pdf`

## Features

- **Author Highlighting**: Your name (Shuang Song) is highlighted in bold
- **Corresponding Author**: Marked with asterisk (*)
- **Year Emphasis**: Years are displayed in the margin
- **Two Sections**:
  - A) Publications with peer review process (articles)
  - B) Publications without peer review process (conferences)
- **Dissertation Note**: Lists publications that evolved from doctoral dissertation

## Troubleshooting

### Common Issues

1. **Missing Biber**: Install Biber if not available
   ```bash
   # macOS with MacTeX
   sudo tlmgr install biber
   ```

2. **Font Issues**: The document uses Times New Roman font
   - En-dashes and em-dashes are mapped back to `--` / `---` via `newunicodechar` in
     `main.tex`. Without that mapping XeLaTeX **silently drops** them under Times, turning
     "Human–Water" into "HumanWater" — do not remove it.

3. **Bibliography Errors**:
   - Ensure `My-Publications.bib` is up to date
   - Check that all cited references exist in the bibliography

### Error Messages

- `plnumbering undefined`: This option was removed from the LaTeX file
- `\plyearhl undefined`: This command was commented out
- `Missing character: There is no –`: A dash reached the font without going through the
  `newunicodechar` mapping. It **does** affect output (the character disappears) — add the
  missing mapping rather than ignoring the warning.

## Output

The final PDF contains:
- Complete title page with author name
- Section A: Peer-reviewed publications (articles)
- Section B: Non-peer-reviewed publications (conferences)
- Corresponding author notation
- Dissertation evolution note

The PDF is automatically copied to `static/uploads/pubs.pdf` for website integration.
